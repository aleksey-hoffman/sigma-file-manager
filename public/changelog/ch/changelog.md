# 更新日志

## [3.2.4-beta] - 2026 年 10 月

**摘要：** 窗口太窄时工具栏会折叠成一个「⋯」菜单。之前缩略图大小按钮只加在宽屏那排图标上，一折叠就彻底找不到了。现在两处都有了。

### 改了什么

窗口宽度不足 600px 时，工具栏按钮会折叠进一个「⋯」菜单，里面是返回、前进、向上、位置、刷新、列表／网格切换，以及新建目录、新建文件。

缩略图大小此前**只加在宽屏那排图标上**，从没有在折叠菜单里做过一份 —— 所以窗口一收窄，这个功能就等于消失了，不是藏得深，是真的没有。

现在两处都有，顺序也对齐：宽屏上排在视图切换按钮之后，「⋯」菜单里排在同名的那一项之后，两处打开的是同一个弹窗。

### 这是测试版

本次构建的其余部分与 3.2.3-beta 相同，包括分屏的左右互换按钮和地址栏那几项。

## [3.2.3-beta] - 2026 年 10 月

**摘要：** 分屏显示时，搜索框右边多了一个「左右互换」按钮，一键对调两格显示的文件夹。两边都拖到位之后，想把左边那个换回左边，就用它。

### 怎么用

开着两格时，**每格工具栏**的搜索框右侧会出现一个左右互换按钮。点一下，两格就此对调：左边刚才显示的，右边开始显示；右边刚才显示的，左边开始显示。

两格各自的窗口宽度、以及在标签组里的先后顺序都保持不变，**只换文件夹**。

只有一格时按钮不出现 —— 没有另一格可换，摆出来只是个按了没反应的东西。

### 两格本来就开着同一个文件夹

什么也不会发生，这是刻意的。交换两个一模一样的文件夹本就没有意义，让面板闪一下一个你看不见的变化反而更让人困惑。

### 这是测试版

本次构建的其余部分与 3.2.2-beta 相同，包括地址栏那几项：粘路径按回车直接进；打开地址栏时当前路径整条选中。

## [3.2.2-beta] - 2026 年 10 月

**摘要：** 文件浏览器的地址栏现在按 Windows 自带资源管理器的方式工作了。点一下地址栏，它就原地变成输入框、当前路径整条选中；粘一条路径按回车，直接进那个地方。下面那个列表的第一行现在就是你正指向的目标目录，默认选中，它的子目录和文件缩进一格排在下面，左侧带树形导线。

### 改了什么

**打开地址栏时，当前路径整条选中。** 点地址栏、或点它旁边的「编辑地址」按钮，整条路径会被高亮选中，可以直接粘贴一条新的把它整条替换掉。以前光标是落在末尾的，粘贴会追加在旧路径后面，拼出一个「旧路径 + 新路径」的诡异结果。想在原路径后面续写，按一下 End 就行 —— 资源管理器也是这么做的。

**输入路径按回车，现在真的会进那个路径。** 以前只有末尾带斜杠的路径才被当成目录。粘 `D:\photos\2026`（不带结尾斜杠）只会得到一条搜索结果，而不是那个文件夹本身。像 `photos` 这样的裸词仍然按名字搜，按名称查找的行为没变。

**回车不再等列表刷新。** 刚粘完的一小段时间里，候选列表还没刷新好，这时候按回车以前是什么都不做。现在直接以输入框里的内容为准，立刻生效。

**方向键和回车的行为没变。** 如果你用方向键选中了某个文件再按回车，打开的仍然是那个文件 —— 输入框里的路径不会覆盖你的选择。

### 候选列表长什么样

列表现在读起来是一棵小树。第一行是目标目录：顶格、字重更重，打开时就选中，按回车直接进去。子目录和文件统一缩进一格、彼此齐平，左侧一根竖线串下来，每行一条短横线指向图标，最后一行收尾。目录排在文件前面，各自按名称排序。

### 这是测试版

这是测试构建。地址栏本体目前仍是面包屑导航、候选列表仍以对话框形式打开；把它改成像资源管理器那样直接贴在地址栏下方，已经列入计划，但不在本次构建里。

## [3.2.1-beta] - 2026 年 10 月

**摘要：** 文件管理器现在可以被 AI 助手指挥。到「设置 → 实验性功能」里打开内置的 MCP 服务、选一个权限档位，Claude Code、Minimax Code 这类助手就能用一套通用接口读你的硬盘、浏览文件夹、搜索文件。本测试版只提供 6 个只读工具，移动、改名、删除一个都做不到。

### 让 AI 助手连上来

服务只监听本机（127.0.0.1），端口在启动时自动挑一个。「设置 → 实验性功能 → MCP 服务」里会直接显示完整地址，以及给各类助手准备好的配置片段，照抄即可，不用手打。

三道防护默认开启、无法关闭：

- **只监听本机。** 局域网里别的设备即使知道地址也连不上。
- **随机访问密钥。** 第一次打开服务时会生成一串四段式密钥，没有它的请求一律拒绝。
- **拒绝陌生网址发来的请求。** 只接受来自本机地址的访问。

### 四个权限档位

随时可切，**切换在下一次工具调用就生效**，不需要重连：

| 档位 | 助手能做什么 |
| --- | --- |
| 关闭（默认） | 什么都不做，服务根本不启动。 |
| 只读 | 下面这 6 个工具。 |
| 可写 | 留给后续版本。 |
| 每次审批 | 每次调用都先在应用里弹确认，等你同意才执行。 |

### 6 个工具

- **列出硬盘** —— 本机所有盘符，带名称和剩余空间。
- **列出可移动设备** —— U 盘、网络共享，可连接也可断开。
- **浏览文件夹** —— 你指定目录下的内容。目录太大会截断，并明确标出已截断。
- **搜索文件** —— 按文件名搜，可搜整盘索引也可只搜某个目录，选项与应用里的搜索框一致。
- **计算目录大小** —— 某个目录连子目录一共占多少空间，最慢的情况封顶两分钟。
- **读取收藏** —— 你在应用里加星的分类和路径。

### 谁问过什么，都会记下来

每次调用都会写进应用设置目录旁边的一个纯文本日志，包含调用的是哪个工具、时间、是放行还是拒绝。想核对助手都干了什么，用记事本打开就行。

### 一键装进各家助手

照抄一段 JSON 到别人家的配置文件里,最容易出的错就是少一个逗号 —— 助手的反应
只是「没有配置任何服务」,你根本看不出哪里错了。「设置 → 实验性功能 → MCP 服务」
现在会列出本机上能识别到的助手 —— Codex、Cursor、Claude Code、Claude Desktop、
OpenClaw、Minimax Code —— 并写明**每一家的配置文件放在哪**,一键替你写好。
同一个界面也能一键移除,不必再去翻文件找那一行删掉。

写配置这件事守三条规矩,因为改的是你自己的配置文件：

- **只合并,不重写。** 先解析文件,只增删那一个条目,再写回。文件里别处的设置 ——
  包括 Codex `config.toml` 里的注释 —— 都保持原样。
- **读不懂就不写。** 解析失败的文件原封不动并明确报错,而不是替换成一份
  看起来对、其实不是的内容。
- **每次写之前先备份**,存成 `<原文件名>.alpha-mcp.bak`。

写入之后需要重启对应的助手才会生效,所以面板上会常驻一条提示,写明改了哪个文件、
备份放在哪里。

### 这是测试版

只提供读取操作。任何可能改动或删除你文件的操作都被刻意拿掉了。权限模型和配置面板在正式版前仍可能调整，各语言的界面文案也未必都已定稿。

## [3.1.3] - 2026 年 10 月

**摘要：** 目录内搜索此前有两处缺陷导致「看起来没实现」，本版一并修掉；搜索选项从弹窗搬到你看得见的位置；搜索后分屏改成左边目录、右边结果。

### 目录内搜索：递归搜索此前确实没生效

这是本版最要紧的一处修复，由两个独立的原因叠在一起造成：

- **遍历上限数错了对象。** 递归遍历有一个「扫够就收工」的上限，但它数的是**扫过的条目数**而不是命中数，上限又是结果条数上限的 20 倍（默认 50 × 20 = 1000）。于是在一个 43,167 个条目的照片目录里，遍历到第 1000 个条目就收工 —— 表现和「只搜当前层」一模一样。现在改为按命中数收工，扫描量的安全阀单独放宽。
- **短查询的命中被评分门槛丢掉了。** 文件名子串命中之后还有一道分数门槛，而三位数字的查询门槛高达 0.9：搜 095 命中 20251009_0095_27.jpg 的得分只有 0.82，于是**当场被丢弃**。这与目录大小无关，小目录也一样搜不到。现在分数只用于排序，不再当门槛。

因此上一版更新日志里「目录内搜索已递归化」那句话，当时并不成立。

### 搜索选项搬到结果正上方

显示文件 / 显示目录 / 精确匹配 / 拼写容错 / 结果条数上限，此前收在过滤框里的一个按钮加弹窗中 —— 而调选项的目的恰恰是**看着结果变**，藏在弹窗里每调一次都要开合一次浮层。现在它们常驻显示在搜索结果上方，改一个勾就能一直看着列表更新。

**拼写容错这次是真做了实现**，不是摆设：递归搜索的粗筛在子串没命中时也会算一次相似度。关闭时拼错的查询依然搜不到，开启才会命中 —— 两个方向都有测试守着。

目录内搜索与全局搜索现在**用的是同一套选项**，不再各说各话。

### 搜索后分屏：左边保持目录，右边是搜索

此前打开全局搜索会把搜索界面顶到左边、目录被挤到右边。现在反过来：**左侧保持目录视图，右侧切到搜索界面**，与「打开所属目录」的布局一致。

### 搜索深度默认 7 层 → 9 层

已有安装会通过数据迁移一并改成 9 层 —— 只改默认值对已经装机的用户无效，因为他们本地的设置里已经写着 7。你自己手动调过的深度不会被覆盖。

### 其他

- **右键「添加到收藏」增加分类选择**：可选已有分类，也可当场新建一个。

## [3.1.2] - 2026 年 10 月

**摘要：** 缩略图大小不再让「没有缩略图」的行和卡片白白长高，列表多列文字垂直居中，并交付目录树、侧边栏与收藏分组这批工作。

### 缩略图大小终于按「行」对齐了

调缩略图大小时，网格视图里目录卡和非媒体文件卡会跟着一起长高，行里多出来的全是空白 —— 它们本来就没有缩略图。现在这两种卡片的高度固定住了：

- **目录卡四档同高**，不再随档位变化；
- **非媒体文件卡固定高**，只改宽度（决定一行放几张卡），高度不变；
- 「小」档整体上移一档，**卡片内容不再被截断**（此前说明行只剩顶部一条）。

这批调整也把四档的像素与行高收进了**同一张度量表**，虚拟滚动、CSS 变量和卡片实际尺寸从此不会再各说各话。

### 列表视图：行高恒定，多列文字垂直居中

和网格是同一件事的第二处：

- **目录行与非媒体文件行的高度不再随缩略图档位变化**，固定为「中」档的默认高度（64 逻辑像素）；
- **图片、视频行仍按档位缩放**，缩略图不会被裁掉。

垂直对齐上，「项目 / 修改时间 / 创建 / 类型 / 链接状态」几列此前是**顶部对齐**，现在与「名称 / 大小 / 标签 / 链接数」一致，**垂直居中**。

顺带修掉一个一直没生效的样式：链接状态列的类名在组件与样式表里写法不一致（驼峰 vs 连字符），**选择器一次都没命中过**，该列此前一条样式都没吃到。

### 「打开所属目录」按你期望的样子拆开了

搜索结果右键「在 Alpha 中打开所属目录」，此前会新开一个标签页，现在改为**拆分窗口**：

- **左侧是所属目录，右侧是搜索结果**，两格并列，搜索结果列表保留；
- 菜单文案一并订正。

### 目录树能滚到底了

目录树此前超出面板且无法滚动，节点多时**最后几个目录看不到**。现在它是真实滚动容器，滚到底可见最后一个节点。

### 侧边栏按你收藏的东西分组

- 快捷面板新增**「常用 / 历史」分组**，删掉两行冗余标题，点分组标题切到仪表盘页签；
- **收藏夹、已标记默认展开**，常用 / 历史默认收起，子菜单缩进，面板加宽；
- 收藏夹与已标记补上了与常用 / 历史一致的**页签跳转箭头**。

### 仪表盘的收藏能按分类分组与编辑

- 仪表盘的收藏区**按分类分组**，并支持编辑；
- 收藏区按**分类 / 目录 / 文件**显示三种不同图标；
- 侧边栏同步分组，并去掉了重复计数。

### 修复

- **新建的收藏分类重启后不再丢失。** 新增的顶层字段此前会被「顶层字段白名单」静默丢弃 —— 界面上一切正常，重启即消失，全程不报错。
- **小房子按钮跳到「此电脑」**，不再是用户主目录。
- **设置页外链菜单已品牌化**，并删除了失效的「讨论」入口。
- 目录内搜索已递归化：在当前目录里搜索可以搜到子目录中的文件。
- 网格框选范围现在**跟随缩略图档位变化后的列宽**。

这一版以打磨为主，没有引入新的设置项或破坏性改动。

## [3.1.1] - 2026 年 10 月

**摘要：** 上传文件时也会跟随路径了（此前只有下载和另存为能跟随），弹窗不再反复闪动，升级安装也不再中途失败。

### 上传时也会跟随路径了

启用 Focus Sync 扩展后，文件对话框会跟着你在 Sigma FM 里浏览的目录走。此前**只有下载和另存为弹窗**会跟随；浏览器**上传文件**时弹出的选择框从来不动。

这两者并不是同一个控件。Edge 和 Chrome 的「另存为」是自己画的，而要你从已有文件里挑一个时，它会把这件事交给 Windows，于是出现两种结构完全不同的对话框。两者对外都报同一种窗口类型，扩展分不出来，就跳过了导航那一步。现在这一步对所有对话框都会执行。

路径也不会再被写进**文件名**输入框了：如果对话框没把键盘放到地址栏上，扩展宁可放弃，也不会把路径打进你正在起名字的那个框里。

### 弹窗不再反复闪动

弹窗有时会在一分钟里闪动、重排几十次。原因是扩展读到的是**列表里第一个文件的文件名**，而不是对话框当前所在的目录；它因此以为目录变了，把同一个路径一遍又一遍地写进去。同一个对话框的读取次数从四分半钟里的 205 次降到了 1 次。

### 升级不再中途失败

覆盖安装时有可能装到一半就停下，且不显示任何报错 —— 安装器自己的清理步骤把安装器自己杀掉了。现已修复，升级可以正常走完。

## [3.1.0] - 2026 年 10 月

**摘要：** 目录树可以右键了，布局切换和缩略图大小终于按预期工作，并修复了 Focus Sync 扩展根本起不来的问题。

### 目录树可以右键了

在目录树的任意节点上点右键 —— 盘符、文件夹、文件都行 —— 会弹出六个操作项：**复制、剪切、粘贴、重命名、打开所在目录、属性**。

- **复制与剪切现在真的能执行。** 此前它们会抛出签名错误，前端找不到内容，菜单里也显示成翻译 key 原文；
- **打开所在目录** 在资源管理器中定位到该文件；
- **属性** 打开该节点的 Windows 属性表。

### 布局切换挪到选项卡

原先在窗口工具栏上的布局切换按钮已经移除，改成「选项卡工具栏上、挨着刷新按钮」的一个按钮。

更重要的是：**它现在只作用于当前这个文件夹**，不再全局生效。于是同一个目录在两个选项卡可以各用各的布局，换来换去也不会把另一选项卡的视图关掉。

全部全局设置的路径挪到了「设置 → 外观 → 文件视图」那一带。工具栏收起时仍可从折叠菜单里的布局切换项进入。

### 缩略图四档递增

缩略图大小现在有四档：**最小 24 / 小 32 / 大 48 / 超大 54 像素**，可以在选项卡工具栏上改，也可以在「外观 → 文件视图 → 缩略图大小」里改。

**行高会跟着档位一起调整**，所以切换档位时列表不会错位。缩略图只在文件滚动到可见区域时才生成；一个 1000 张图的目录，首屏只加载约 30 张，其余在你滚动时补齐。

### 磁盘同时显示空余与总空间

「位置」里的磁盘条目原先显示的是条数，现在直接显示 `147.1 GB / 931.3 GB`。空余空间和容量一瞥看全。

### 主页与设置

- **主页标题移到了主题图外面**，字号大到可读；点主题图本身则直接打开背景管理；
- **设置页补上了官网与源码仓库链接**，顶部介绍改成本版本在 Sigma File Manager 之上增加了什么，而不是一句通俗的替代品。

### 同时修复

- **Focus Sync 扩展此前会被自家加载器拒掉。** 代码扫描器把扩展 `dist/index.js` 里一句英文**注释**中出现的 `self` 当成了代码里的直接 `self` 访问，于是整份扩展在「启动 Worker 之前」就被拒绝 —— 这就是为什么路径同步看起来像是整体失灵。现在扫描器会跳过注释、字符串、模板串与正则，只扫真正可执行的代码，写在代码里的违规仍然拦得住；
- **Focus Sync 不再跑着跑着就失联。** 此前只要早期有一次写入被拒绝，侧车进程就会把「该对话框已经写过」记下来，于是把自己那套重试通道彻底关掉。表现是：刚打开对话框时还跟得好好的，几分钟后路径同步再也不更新，非得关掉对话框重开才恢复。现在写入失败不会再被当成成功；
- **目录树右键菜单的复制、剪切** 此前会报错、前端找不到内容，现已修复；
- **覆盖旧版本升级时不再把安装程序自己杀掉。** 升级过程中会先运行旧版本的卸载器，而卸载器的「结束应用进程」步骤会把当前这个安装程序当成残留进程一起结束，于是安装在途中失败，且不给任何可读的错误提示。现在任何名为 `*setup.exe` 或 `uninstall.exe` 的进程都会从这一步里排除，**不论它在进程树的哪个位置**；应用本体仍然会被正常结束，exe 文件不会因为还在运行而删不掉；
- **更新弹窗内容现在对得上版本号。** `CHANGELOG.md` 从 2.2.0 之后就没再更新过，于是从 3.0.0 起每一版都默默显示文件里最旧的那一条。现在当某个语言的翻译早于当前版本时会回退到英文条目，并新增 `verify-changelog` 门禁：changelog 没覆盖当前版本号就直接让构建失败；
- 设置页顶部介绍已换成本项目自己的文案，不再是上游的占位文字。

## [3.0.0] - 2026 年 10 月

**摘要：** Alpha File Manager 品牌化后的首个正式版本。新增批量改名，窄侧栏中的磁盘现在一眼可辨，弹窗焦点同步扩展也完成了一轮实质性加固。

本版本同时将产品名从 Sigma File Manager 统一改为 **Alpha File Manager**，覆盖界面、安装器与报错文案。项目来源不变，原有设置与布局会完整保留。

### 批量改名

一次改同一个目录里的多个文件，落盘之前有实时预览。

- **入口**：选中两个及以上项目，右键选择 `批量改名`。单选仍然走原有的 `重命名`；
- **规则**：查找替换（可选区分大小写、可选包含扩展名）、大小写转换（全部大写、全部小写、首字母大写、驼峰、下划线、短横线）、模板命名、序号、扩展名批量修改。规则按显示顺序依次生效，可以调整顺序；
- **模板变量**：`{name}`、`{ext}`、`{parent}`、`{size}`、`{date}`、`{n}`，日期支持 `{date:YYYYMMDD}` 格式并使用本地时间；
- **实时预览**：边输入边显示每个条目的原名与新名。没有变化的行会置灰；
- **冲突阻断**：新名撞上批次之外的已有文件时**阻断而不是覆盖**；两个条目生成同名时阻断并指出是哪两个；`a → b` 与 `b → a` 这类交换循环通过两阶段自动腾空处理，用户看不到任何临时文件；
- **撤销**：保留最近 10 批操作，可一键还原，执行到一半失败的批次也能还原。撤销前会重新检查冲突，宁可拒绝也不会覆盖你之后的改动；

序号只为模板中的 `{n}` 供值，自身不改名，需要配合模板规则使用。

### 侧栏盘符标识

窄侧栏里的多块磁盘现在可以一眼区分。

- **图标上叠加短标签**：按挂载点提取短标识 —— `C`、`D`，网络路径则显示共享名；
- **为什么需要**：侧栏那一列只有 24px 宽，而所有磁盘图标长得一模一样，认不出哪个是哪个分区；
- **随主题的描边**：字标用侧栏自身底色描 2px，并采用 `paint-order: stroke fill`，把图标线条从字形后面「抠断」。浅色与深色主题下都清晰；

目录树面板也略微加宽，目录名不必拖动分隔线就能看清。

### 弹窗焦点切换

Focus Sync 扩展（`kizemo.focus-sync`）升级到 0.5.8，完成一轮正确性加固。它能把 Windows 文件对话框 —— 包括其它程序的「另存为」—— 定位到 Alpha File Manager 中当前所在的目录。

- **不再重复写入**：同一个对话框不会再在约 900 毫秒后被定位两次，此前表现为地址栏可见地跳一次；
- **窗口激活竞态**：Windows 激活窗口时会经过一个存在时间极短的 `ForegroundStaging` 临时窗口。扩展现在会等待对话框重新成为前台（上限 500 毫秒），而不是直接放弃并退到一条根本起不到定位作用的路径；
- **如实的还原结论**：还原文件名输入框后会**读回校验**，还原失败返回失败，不再谎报成功；
- **更干净的诊断**：日志环形缓冲区不再被健康检查刷满，「推送丢了」与「回调压根没触发」现在能在日志里区分开。失效的窗口句柄会被及时回收而不是堆积；
- **sidecar 更安全**：跑测试不再强制结束你正在使用的 sidecar；

### 品牌化

- 应用在界面、安装器、窗口标题与报错文案中统一更名为 **Alpha File Manager**；
- 从 2.2.x 升级到 3.0.0 的安装、升级、卸载路径是稳定的 —— 原地升级会保留你的设置、布局与快捷方式；

### Tauri 迁移

Sigma File Manager v2 使用 Vue 3 Composition API、TypeScript 和 Tauri v2 从零开始重建。Windows 上的应用安装大小从 153 MB 减少到仅 4 MB。已安装应用大小从 419 MB 减少到 12 MB。

### 可调整大小的面板

添加了可调整大小的面板功能，让您可以将导航器视图一分为二，同时处理两个目录。

### 初始功能

基本的文件导航，包含目录列表、带有最小化、最大化和关闭控件的窗口管理，以及初始设置页面结构。
