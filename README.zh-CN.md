<h1>&nbsp;&nbsp;Alpha File Manager</h1>

**一款面向 Windows 与 Linux 的现代文件管理器 —— 补上资源管理器最缺的两件事：
一棵真正的目录树,以及会跟着你跨应用走的文件对话框。**

Alpha File Manager 是 [Sigma File Manager](https://github.com/aleksey-hoffman/sigma-file-manager)
的独立衍生版本,由 [kizemo](https://github.com/kizemo) 维护。它跟随上游同步,并在其上叠加了
一棵目录树、跨应用的文件对话框路径同步,以及一长串日常使用中的细节修复。

> [!IMPORTANT]
> **Alpha File Manager 是独立的社区项目**,与 Sigma File Manager 项目无隶属关系,
> 未获其认可或官方支持。基础应用的功能与品牌归
> [Aleksey Hoffman](https://github.com/aleksey-hoffman) 所有。

## ⚖️ Alpha File Manager vs Sigma File Manager vs Windows 资源管理器

三样东西,三种活法。下面是它们之间**如实**的对比。

| | | Alpha File Manager | Sigma File Manager | Windows 资源管理器 |
|---|---|---|---|---|
| 🖥️ | **跑在哪** | Windows + Linux | Windows + Linux | 只有 Windows |
| 🌲 | **左侧目录树** | ✅ 常驻的一棵树,跟着你正在用的那一格走 —— 远程也能成树 | ➖ 没有 | ✅ 在导航窗格里 |
| ⭐ | **常用文件夹一键直达** | ✅ 收藏按分类分组、可以编辑,添加时还会问「归到哪一类」,常用集合一点就进 | ➖ 没有分类,添加时也不问 | ➖ 只能钉在「快速访问」,没有分类 |
| ⚡ | **别的应用里的文件对话框** | ✅ **Focus Sync** —— 任何对话框都开在你正在浏览的目录 | ➖ | ❌ |
| 🤖 | **让 AI 助手驱动它** | ✅ 内置 MCP 服务,六家助手一键部署 | ❌ | ❌ |

| 📤 | **在远程文件上干活** | ✅ 上传、下载、删除、改权限 | ❌ | ➖ 只有网络共享 |

| 📊 | **显示哪些列** | ✅ 按位置决定 —— 「位置」页会去掉那些根本没话说的列 | ➖ 所有目录一套列 | ➖ 所有目录一套列 |

| 🖼️ | **缩略图尺寸** | ✅ 四档可选 | ➖ | ➖ 跟随系统 |
| 🧠 | **批量改名** | ✅ 查找替换、大小写转换、模板与编号 —— 带实时预览,冲突当场拦下而不是静默覆盖,还能撤销 | ❌ Sigma 里根本没有这个功能 | ✅ 有查找替换,也带预览 |
| 🫳 | **把文件拖到别的程序里** | ✅ **按住文件就能拖出去** —— 微信、钉钉、浏览器都行,而且拖的那个窗口待在后台不抢前台 | ➖ | ✅ |
| 👁️ | **拖的时候目标程序提到前面** | ✅ 鼠标停在哪个应用上,哪个窗口就替你带到前面,落点一眼就看见 | ➖ | ➖ Windows 的拖拽不会把目标窗口提到前面 |
| ⌨️ | **键盘连选** | ✅ **Shift + 方向键**从你起手的锚点往外扩选 | ➖ | ✅ Shift + 方向键也能扩选 |
| 🔍 | **比较两个目录** | ✅ 递归比较,准则跟专业工具同一套 —— 并且有明确的「方向待定」,而不是猜哪边更新 | ➖ | ➖ 只比大小与日期,选项藏得很深 |
| 🌐 | **映射网络驱动器** | ✅ 从侧边栏就能做,盘符自己挑 | ➖ | ✅ |
| 🎨 | **背景效果支持混合模式** | ✅ Photoshop 的图层模式全套,还能配自己的填充色 | ➖ | ❌ |

✅ 有 · ➖ 这个项目里没有 · ❌ 做不到

> **你想要的是「Windows 自带的那个」** —— 要 Shell 扩展、要编解码器、要网络共享、要 EFS 加密,
> 还要那种「跟什么都能对上」的踏实感,那就用资源管理器。任何第三方文件管理器都替代不了这一点,
> 我们也不会假装可以。
>
> **你想要的是「一个窗口里,本地磁盘和远程服务器并排待着」** —— 助手还能通过一套通用接口读你的盘,
> 目录树能跟着你走进其中任何一边,这就是 Alpha File Manager。资源管理器不带 SFTP 客户端,
> 也不存在「让助手看见你的文件」这件事,除非你再装一个第三方桥接。
>
> **Sigma File Manager** 是我们构建时用的底座。想要上游项目本身、它自己的发版节奏和它的社区,
> 就去用它。Alpha File Manager 是它的独立衍生版本,并且一直跟着上游同步。

## 🆕 3.4.0 新增了什么

### 🔍 并排比较两个目录,再按结果同步

把导航器分成左右两格,工具栏上就多一个**「比较并同步」**按钮。它递归地比较这两个目录,
告诉你哪里不一样:只在左边的、只在右边的、哪一边更新的、大小或内容不一样的。
结果用**树**显示 —— 整个只在一侧存在的子目录会读作一个子树,而不是一堆没有上下文的散名字。

准则跟专业工具用的是同一套,顺序照抄 WinSCP:**先看修改时间,再看文件大小,最后看内容校验和**。
时间优先 —— 时间不一样的时候,大小根本不看。一个准则都不勾时,判据就是「两边都有这个文件」,
于是只会报出真正新增的条目。

### 🧭 判不准的时候,它会直说,并且什么都不做

两个文件**时间戳一样、内容不同**,这是最难办的一种情况:左边那份并不比右边旧,
可它们又不是同一个文件。这种情况下自动同步必然有一边被覆盖掉,而覆盖哪个,
取决于实现里某个隐含的约定。

Alpha File Manager 把这类标成**「方向待定」**,原样放着。它们会被单独列出来让你自己决定,
但**绝不会在你背后覆盖掉任何东西**。「一边是目录、一边是同名文件」也是同样处理 ——
那时候目标侧根本没有落脚点,硬做只会产生一堆必然失败的错误。

### 📋 动手之前先给你看计划

预览清单会列出将要新建哪些目录、复制哪些文件、跳过哪些。然后才动第一个字节。
同步在后台跑,有进度条,随时能取消;失败的条目单独列出来。

### 🗑️ 这个功能永远不删东西

同步会补上缺失的文件、更新更旧的那一份。只在目标侧存在的东西会被**报告出来**,
而不是删掉。想做「镜像」(两边完全一致,多出来的删掉),留到后面的版本。

### 🌐 侧边栏里就能映射网络驱动器

侧边栏底部的盘符列表末尾,多了一个**「添加网络驱动器」**按钮 —— 就是 Windows 资源管理器
给了很多年的那个入口,也是你真正会去找它的位置。选共享、选盘符(留空则由 Windows 分配),
挂上之后盘符就出现在侧边栏里,跟别的盘一样。

### 🩹 还有一个小修

**映射网络驱动器之后报出来的盘符多半是空的。** 应用此前在 Windows `net use` 的输出里找
"assigned" 这个词 —— 而 Windows 真正打印的内容里**根本没有这个词**(本机实测输出是
「Drive Z: is now connected to ...」)。盘符明明挂上了,报出来的却是空的。现在改成直接问
Windows:哪个盘符指向那个共享 —— 这跟 Windows 的语言、输出表格的列宽、以及共享名里带不带
空格都无关。

## 🆕 3.3.0 新增了什么

**3.3.0 是 3.3 系列的第一个正式版。** 它把四轮从未单独发布过的 beta 收进了一个包 ——
扩展加固、键盘连选、背景混合模式、长按拖拽 —— 外加从 beta 转正式这一步。

### 🫳 把文件拖到别的程序里,而且不让你的窗口挡路

在文件或目录上按住不放,过一会儿就会起一次真正的 Windows 拖拽。把它拖到微信、
钉钉、浏览器 —— 什么都行 —— 松手就行。同一个手势在 Alpha File Manager 内部
照旧可用:拖到某个文件夹上仍然是移动文件。

要让这件事真正好用,有三件事必须成立:

- **你按下的时候,窗口不会跳到最前层。** Windows 平常是一按下鼠标就把窗口带到前面,
  于是你伸手去够后台窗口里的文件时,那个窗口立刻就把你要放进去的程序盖住了。
  按住不放的时候,Alpha File Manager 待在原地。
- **你拖到哪个程序,那个程序就提到前面来。** 拖着文件走的时候,鼠标停在哪个应用上,
  那个窗口就替你带到前面。对话窗口就在眼前,落点也看得见。
- **松手之后不会把前台抢回来。** 拖拽结束时前台留在原处 —— 你放进去的那个程序继续
  待在前面,接着就能用。

普通单击的行为一点没变:在后台窗口里点文件,窗口照样跳到前面、照样拿到键盘焦点。
只有「按住」这个手势会把窗口按住不让它抢;按住的时候鼠标只要动一点点,这个手势
就变成普通拖拽 —— 所以一直用老方式拖文件的人完全不受影响。

### 🎨 背景效果,像 Photoshop 一样混合

效果层 —— 铺在应用后面的那层模糊、带颗粒的底色 —— 现在可以按熟悉的图层模式与界面
叠加:变暗、正片叠底、颜色加深、变亮、滤色、颜色减淡、线性减淡(添加)、叠加、柔光、
强光、差值、排除、颜色、明度。菜单按 Photoshop 的方式分组,WebView 实际上画不出来的
模式会被直接藏起来,而不是摆在那里让你选了却没反应。

除「正常」以外的每种模式还可以指定**跟什么混合**。保持「界面」时,效果和窗口下层
混合,跟以前一模一样;切到「填充色」,效果就跟你挑的颜色混合 —— 八种现成色板,
或者你自己取一个颜色。

鼠标在菜单上往下移,背后的页面会实时预览那个模式。离开菜单时你保存的模式会被放回去 ——
随便逛逛不花任何代价。

### ⌨️ 用键盘连选

在目录里,你按下的那个条目成为**锚点**;之后每按一次 Shift+方向键都从锚点扩展选择范围,
往回按则把范围收回来。不按 Shift 的普通方向键仍然只移动到下一个条目、只选中它,跟以前一样。

### 🔒 扩展再也不能被引到你自己的内网

Alpha File Manager 抓扩展时,现在检查的是它**实际连上去的那个地址** —— 而不是纸面上
写下来的那个名字。如果那个地址落在私有网段、本机回环地址或者保留地址里,下载会被拒绝,
并把拒绝的理由如实报出来。检查发生在连接的那一刻,所以首次请求、重试、备用镜像、
跳转链上的每一跳都算数。

扩展能不能运行一个程序,现在由**它自己的描述文件**说了算 —— 应用从磁盘上读这份文件,
在里面没写明要这项权限,程序就不会被允许启动。冒用别的扩展的身份来问,或者根本不问,
都会被拒绝。而那个「沙箱」没了,因为它本来就不是沙箱:扩展代码本来就跑在别处 ——
自己的 worker,或者沙箱化的 iframe —— 真正的隔离来自那里。

### 🩹 还有一些小修

- **网络盘上的文件可能在你不知情时被永久删除。** 回收站只存在于本地磁盘。以前这一步
  只是失败,文件**照样被删掉** —— 一个字都不说。现在会先问,只有你点头才永久删除。
- **窗口回来时底边可能落在屏幕外。** 现在窗口分阶段恢复,再收进工作区,总能回到你
  够得着的地方。
- **双击顶栏不能最大化窗口。** 顶栏上那块空白此前不是真正的拖拽区,双击根本到不了
  窗口管理器。现在它就是了。
- **最大化按钮可能让窗口同时处于全屏与最大化。** 现在按钮先退出全屏再最大化。
- **文件列表重排之后,长按仍可能把窗口带到前面。** 「指针是否停在可拖拽条目上」改为
  **按指针实际所在的位置**判断,列表重排不再改变答案。
- **外观设置里的颜色选择器不再被藏起来。** 选了「与填充色混合」之后,色板与自定义取色器
  **始终**露出来。

> **从 3.2.12-beta 升上来?** 中间那四轮 beta 从未单独发布过 —— 这一版把它们全包进来了,
> 外加从 beta 转正式这一步。中间不需要装两次。

## 🆕 3.2.11 新增了什么

**3.2.11 是 3.2 系列里第一个能真正浏览远程服务器的版本。** 这一版里落了七轮的工作:
SFTP、FTP、FTPS 连接真的会列出远程目录,目录树跟着你走进去,两格能一起浏览,
能上传、能下载、能删除 —— 上面还压着一长串本地修复。

### 🌐 远程服务器,是真的

三种协议,各一条代码路径:**SFTP**、**FTP**、**FTPS**。保存下来的连接不再只是一条书签 ——
打开它就会列出远程目录,连同文件、大小和日期。

第一次连上一台机器时,你会先看到一个指纹确认框,**确认之前什么都不信任**。SSH 公钥与 X.509 证书
按同一台主机和端口**分开存放**,所以信任其中一个不代表信任另一个;证书变了会明确报成
「证书已变更」,而不是一个含糊的网络错误。所有记住过的主机都列在**设置 → 已信任主机**里,
随时可以撤销。

### 🌲 目录树跟着你走进远程目录

目录树不再只是一串本地盘符。切到远程面板,它就变成远程那棵树:以你给这条连接配的目录为根,
用连接名标注。它会展开到你所在的那一层,把那行滚到眼前,并且**跟着你真正在用的那一格走** ——
远程机器还在建连时,另一格抢不走高亮。

### 🔗 两格,同一段浏览

给连接配一个起始路径,打开时就落在那里,而不是远程根目录。打开**同步浏览**,
两格就一起走:在本地进入 `wp-content`,远程那格也进 `wp-content`;往上退一级,
另一格也跟着一退。

### ⬆️⬇️ 上传、下载 —— 以及自己刷新的那一格

把文件或整个目录传到远程那侧,或者从远程拉回来。传输一结束,
**收到东西的那一格会重新读一次自己的目录**,新文件立刻就在,不用等你手动刷新。
刷的是**它自己**,而且只在它还显示着收到文件的那个目录时才刷。

### 🗑️ 删除远程文件

远程文件原来**完全没有**删除入口。现在有了 —— 只给一个**「删除」**,
不给「移至垃圾箱」这种根本做不到的选项,因为远程服务器上没有回收箱。
删之前会先说清楚,而且你的账户要是没权限,服务器怎么拒绝就怎么报。
菜单项**永远不隐藏**:前端判不准你在服务器上是属主、属组还是其他人。

### 🔐 权限从列表里挑

给远程文件设权限原来要自己敲八进制,而**敲错一位就是悄悄放宽或收紧了别人对这个文件的访问**。
现在是一个常用模式的下拉,每一项都带着 `rwxr-xr-x` 形式。文件当前那个权限**一定在列表里**,
所以打开对话框、什么都不改、直接应用,等于什么都没改。

### 🏠 新标签页打开的是「位置」,而且能看出盘用了多少

点 **+** 原来落在用户文件夹,现在落在**「位置」**页。每张分区卡片按**已用比例**填充,
分三档强弱;列表视图里「大小」右边多了一列**「可用空间」**。
「位置」页不再有**修改时间**和**创建时间**两列 —— 磁盘既没有修改时间也没有创建时间,
那两列整列都是横杠,占着宽度什么都不说。换到别的目录,反过来去掉的是「可用空间」列,
理由一模一样。

### 🧹 几件小事,但值得知道

- 工具栏那个垃圾桶图标原来浮出来的是**悬停提示**,点不着。现在是真正的菜单,
  每一项旁边还标着快捷键。
- 已保存的连接列表现在在启动时、窗口显示之前就会读完。以前**「权限设置」**入口和
  树根上的连接名会安安静静地不工作,直到你恰好去过一个会加载这份列表的界面。
- 目录树会滚到你正在用的那个目录,而且只留一个根,不再自己冒出额外的根来。

### 🧪 这个包里没有的

- **向远程复制目前没有实现。** 上传和下载是各自独立的入口,它们是能用的;
  跨本机与远程之间的复制、剪切、粘贴,给远程条目改名,以及在远程目录里新建 —— 这些还没有。
- **FTPS 的文件内容目前还是明文。** 控制通道有证书固定保护,但数据通道仍用服务端默认行为,
  也就是文件内容在链路上是明文。`PBSZ` / `PROT P` 没有发。
- **FTPS 从来没有连过真实服务器。** SFTP 有。

完整清单 —— 包括哪些部分是在装好的应用上验过的、哪些是靠测试覆盖的 —— 在
[更新日志](https://github.com/kizemo/alpha-file-manager/blob/main/CHANGELOG.md)里。

## 🆕 3.2.4 新增了什么

**3.2.4 是 3.2 系列的第一个正式版。** 地址栏按资源管理器的方式工作了,分屏可以
左右互换,缩略图大小在窗口变窄时也找得到。它取代 3.2.1-beta —— 那是最后一个

### ⌨️ 地址栏按资源管理器的方式工作

点一下地址栏,它就原地变成输入框,当前路径**整条选中**;粘一条新路径按回车,
直接进那个地方。以前光标落在末尾,粘贴会追加在旧路径后面,拼出一个「旧路径 +
新路径」的诡异结果;想在原路径后面续写,按一下 End 就行 —— 资源管理器也是
这么做的。

三个缺陷是一起修掉的,任何一个单独存在都足以让「粘一条路径」变得不可靠:

- **只有末尾带斜杠的路径才被当成目录。** `D:\photos\2026` 不带结尾斜杠,
  回来的会是一条搜索结果而不是那个文件夹本身。像 `photos` 这样的裸词仍然
  按名字搜,按名称查找的行为没有变化。
- **回车不再等列表刷新。** 刚粘完的一小段时间里候选列表还没刷新好,这时候
  按回车以前是什么都不做。现在直接以输入框里的内容为准,立刻生效。
- **方向键仍然优先。** 用方向键选中某个文件再按回车,打开的仍然是那个文件 ——
  输入框里的路径不会覆盖你的选择。

### 🌲 候选列表读起来是一棵小树

第一行就是你正指向的目标目录:顶格、字重更重,打开时就选中,按回车直接进去。
子目录和文件统一缩进一格、彼此齐平,左侧一根竖线串下来,每行一条短横线指向
图标,最后一行收尾。目录排在文件前面,各自按名称排序。

### ↔️ 分屏两格可以左右互换

开着两格时,**每格工具栏**的搜索框右侧有一个左右互换按钮,点一下两格就此对调 ——
**只换文件夹**,两格各自的窗口宽度、以及在标签组里的先后顺序都保持不变。
两格本来就开着同一个文件夹时什么也不会发生,这是刻意的。

### 📐 窄窗口下也找得到缩略图大小

窗口宽度不足 600px 时,工具栏会折叠成一个「⋯」菜单。缩略图大小此前**只加在
宽屏那排图标上**,所以窗口一收窄,这个功能就等于消失了 —— 不是藏得深,是真的
没有。现在「⋯」菜单里也有它,排在同名的那一项之后,两处打开的是同一个弹窗。

> **仍然是只读的。** 3.2.1-beta 引入的 MCP 服务原样保留,本版本没有任何功能能
> 移动、改名或删除你的文件。

## 🆕 3.2.1-beta 新增了什么

**3.2.1-beta 是 AI 版本：文件管理器内置了 MCP 服务,助手可以直接读你的硬盘,
不必再靠截图猜。**

### 🤖 助手现在能直接问你的文件管理器

[Model Context Protocol](https://modelcontextprotocol.io)（MCP）是 Claude、Codex、
Cursor 以及越来越多助手本来就会说的接口。在「设置 → 实验性功能」里打开服务,
它们就能列出盘符、浏览目录、按文件名搜索、算目录占多大、读你的收藏 ——
而且走的是**已经认识快捷方式、虚拟目录和网络共享**的那个文件管理器。

**6 个工具,全部只读。** 移动、改名、复制、删除一个都做不到,而且写操作
不是「默认关着」,是**根本没实现**。

| 工具 | 它回答的是 |
| --- | --- |
| `list_directory` | 这个目录里有什么？ |
| `get_drives` | 本机有哪些盘,各剩多少空间？ |
| `get_mountable_devices` | 哪些 U 盘和共享可以连接？ |
| `search_files` | 叫这个名字的文件在哪？ |
| `get_directory_size` | 这个目录连子目录一共占多少空间？ |
| `get_favorites` | 这个人收藏了什么？ |

### 🔒 三道防护,一道都不能关

- **只监听本机。** 服务只绑 127.0.0.1,局域网里别的设备即使知道地址也连不上。
- **随机访问密钥。** 第一次打开服务时生成,不带它的请求一律拒绝。
- **拒绝陌生网址发来的请求。** 只接受来自本机地址的访问。

四个权限档位,而且**每次调用都会重新查一遍** —— 调低档位在下一次请求就生效,
不用重连。

### ⚡ 一键装进各家助手

照抄一段 JSON 到别人家的配置文件里,最容易出的错就是少一个逗号 —— 助手的反应
只是「没有配置任何服务」,什么线索都不给你。「设置 → 实验性功能 → MCP 服务」
现在会列出本机上能识别到的助手,写明**每一家的配置文件放在哪**,一键替你写好;
同一个界面也能一键移除。

因为改的是**你自己的**配置文件,写入守三条规矩：

- **只合并,不重写。** 先解析文件,只增删那一个条目,再写回 —— 文件里别处的设置,
  包括 Codex `config.toml` 里的注释,都保持原样。
- **读不懂就不写。** 解析失败的文件原封不动并明确报错,而不是替换成一份
  看起来对、其实不是的内容。
- **每次写之前先备份**,存成 `<原文件名>.alpha-mcp.bak`。

写入之后需要重启对应的助手才会生效,所以面板上会常驻一条提示,写明改了哪个文件、
备份放在哪里。

### 📜 谁问过什么,都会记下来

每次调用都写进应用设置目录旁边的日志：调用的是哪个工具、时间、是放行还是拒绝。
纯文本,想核对就用记事本打开。

### 🧪 这是测试版

只提供读取操作,这是刻意的。权限模型和配置面板在正式版前仍可能调整,
各语言的界面文案也未必都已定稿。

## 🆕 3.1.0 新增了什么

**3.1.0 收录的是我们把软件改名为 Alpha File Manager 之后新增的全部内容。**
3.0.0 是品牌化正式版,3.0.1 修复了批量改名的数据丢失,3.0.2 加入列表缩略图,
本版本是建立在这些之上的打磨。

### 🧭 导航

- **目录树有了右键菜单。** 在任意节点上右键 —— 盘符、目录、文件 —— 弹出
  **复制、剪切、粘贴、重命名、打开所在目录、属性**。剪贴板里确实有内容时
  「粘贴」才会出现。「重命名」复用文件列表同一套对话框,无论从哪里触发,行为完全一致。
- **布局切换按钮移到选项卡工具栏**,紧挨着刷新按钮,并且改为**只作用于当前文件夹**
  而非全局。同一个目录的两个选项卡现在可以各用各的布局,切换选项卡也不会再互相覆盖。
  如果你更习惯原来的全局路径,折叠的 ⋮ 菜单里「仅此文件夹」仍然保留。
- **磁盘同时显示空余空间与总空间。** locations 里的磁盘条目显示
  `147.1 GB / 931.3 GB`,不再显示条目计数。

### 🖼️ 缩略图

- **四档缩略图尺寸。** 小(24 像素)、中(32 像素)、大(48 像素)、超大(54 像素) ——
  可在选项卡工具栏或**「设置 → 常规 → 文件视图」**中选择。行高随档位联动
  (42 / 42 / 64 / 70 逻辑像素),切换档位时列表不会错位。
- 缩略图**按需生成**:只为滚动到可见区域的行生成。

### 🏠 主页与设置

- **主页标题移出主题图**,放在图外并放大到可读尺寸。点击主题图本身则直接打开背景管理。
- **设置页补上官网与源码仓库链接。** 顶部介绍改为描述**本版本**在 Sigma File Manager
  之上增加了什么,而不是上游的通用简介。

### 🔧 修复

- **Focus Sync 在应用运行几分钟后会"哑掉"。** 伴生进程把一次**被拒绝**的写入也记成了
  「已写入」,结果把自己的重试通道永久关闭 —— 于是一次早期失败之后,后续所有路径变化
  都被忽略,直到你关掉对话框重新打开。现在写入失败不再被记成成功。
- **扩展加载器拒绝了我们自己的扩展。** 代码扫描器把内置扩展里一句英文**注释**中的
  `self` 当成了违规,于是 Focus Sync 在 Worker 启动之前就被拒绝 —— 这正是路径同步
  看起来"整体失效"的原因。扫描器现在会跳过注释与字符串字面量,同时也仍然拦截
  可执行代码里的真实违规。
- **目录树右键的复制 / 剪切签名错误**,剪贴板拿不到内容。

### 📦 安装器

- 升级与卸载现在会**结束整个应用进程树**,残留的辅助进程无法再占住文件导致安装中断。

> **版本脉络:** 2.2.x → **3.0.0** 品牌化 → 3.0.1 改名数据丢失修复 →
> 3.0.2 列表缩略图 → **3.1.0** 本版本。

## ⚡ Focus Sync —— 会跟着你走的文件对话框

在 Alpha FM 里浏览到某个目录,然后在**任意** Windows 应用里打开
**另存为 / 打开**对话框 —— Chrome 下载、Word、VS Code、钉钉、飞书 ——
它已经停在你刚才那个目录里了。

**零配置。** 安装包已内置扩展与一个小型本地伴生进程,Windows 计划任务会在登录时自动启动。
**不需要手动运行任何东西。**

**它给自己定的三条规矩**

| | |
|---|---|
| **绝不抢焦点** | 对话框不在前台时,写入会等待,绝不强行切换。 |
| **绝不弄脏文件名框** | 目标是地址栏。当回退路径必须碰文件名框时,它会还原原始值并**读回校验**后才提交。 |
| **绝不写入陈旧路径** | 若 Alpha FM 未在运行,则拒绝写入,而不是把你上次待过的目录灌进对话框。 |

扩展只申请 `commands`、`toolbar`、`notifications`,以及对 `127.0.0.1` 的 HTTP 访问 ——
**无 shell 权限,无文件系统权限。**

> **状态** —— 仍在加固中。已在原生 Win32 对话框上验证;
> Chromium 与 UWP 宿主的表现因宿主而异。
