**已知边界（不是缺陷，但值得知道）：**

1. **MCP 工具不支持热加载。** Minimax Code / Claude Code 等客户端在会话启动时枚举一次工具列表。中途添加 MCP 服务后，**必须新开会话**才能看到那些工具；本会话内看不到属正常现象。
2. **`list_directory` 遇到不存在的目录**返回 JSON-RPC 错误 `code: -32603`（`Path does not exist: ...`），符合协议规范，不是静默返回空。
3. **端口会随启动变化。** 重启电脑或端口被占时可能不是 55100，需要回设置页取当前地址重新配置客户端。

## 零、先看这一页：这个功能到底在干什么

以前，AI 助手看不到你电脑里的文件。你要它帮你找一张照片，得自己翻目录、再把路径贴给它。

现在，Alpha File Manager 变成了一个「对外开门的窗口」。你在设置里打开开关，AI 助手（比如你现在用的 Minimax Code、或者 Claude Code）就能**代表你**来问这个应用：

- 我这台电脑有哪些盘？
- 某个文件夹里有什么？
- 帮我找一张叫「合同」的文件。
- 这个文件夹占多大地方？
- 我收藏了哪些东西？

**它只能看，不能动。** 这一版没有「删除」「改名」「移动」这类功能，任何一个都碰不到你的文件。这是刻意的设计，不是没做完。

打个比方：以前你家的门是锁死的；现在你自愿开了一扇**只能往外看**的窗口，而且钥匙（token）只有你自己知道。

## 一、开始之前：请先关掉其他同类程序

为了保证结果干净，请先**完全退出**下面这些程序（不是最小化，是从任务栏托盘里右键退出）：

- Alpha File Manager 的旧版本（如果你装过）
- Claude Code、Minimax Code、OpenClaw 等 AI 助手命令行窗口

然后重新安装本版本。

---

## 二、安装

1. 双击安装包。
2. 一路点「下一步 / 安装 / 完成」，不需要改任何选项。
3. 打开应用。

**先确认版本对不对：** 标题栏或设置页显示的版本应该是 **3.2.1-beta**。

> 如果显示的是 3.1.3，说明装的是旧包，停下告诉我。

---

## 三、验收第一步：找到这个新功能藏在哪

1. 点左上角的 **设置**（齿轮图标）。
2. 在左侧分类里找 **实验性功能**。
3. 里面有一个条目叫 **「MCP 服务（AI 接入）」**。

**这里有个关键点，和别的设置不一样：**

刚装好时，这个功能是**完全关闭**的。关闭状态下，应用**不监听任何网络端口**，你电脑上任何程序都连不上它。

> 为什么要这样设计？因为哪怕是本机，连上来的也可能是你不认识的其他程序。默认关着，你随时能自己决定什么时候开门。

**你应该看到：** 一个权限档位选择器，当前停在「关闭」。

---

## 四、验收第二步：打开开关，看服务有没有起来

1. 在「MCP 服务」这一页，把档位从「关闭」改成 **「只读」**。
2. 等 2 秒。

**你应该看到：**

- 状态从「未运行」变成 **「运行中 · 端口 xxxxx」**（后面跟一个 5 位数，比如 55100）
- 下面出现一行 **端点**，是一个 `http://127.0.0.1:xxxxx/mcp` 这样的地址
- 出现一个 **「复制配置片段」** 按钮
- 出现一个 **token**（一串随机字符）和 **「重新生成 token」** 按钮
- 最下面出现 **「最近调用」** 列表 —— 现在应该是空的

**顺手确认两件事：**

- 地址里的 `127.0.0.1` 在。这表示**只有本机能连**，局域网里的其他设备（手机、别的电脑）连不上。如果地址是 `0.0.0.0` 或电脑的局域网 IP，**这是严重问题，请立刻告诉我**。
- 一长串 token 在，并且长得像乱码（比如 `3f8a9c2e-...`）。这是门锁钥匙。

---

## 五、验收第三步：四个权限档位

页面上有四个档位，挨个点一下，看描述文字对不对：

| 你点的档位 | 页面上应该显示的意思 |
|---|---|
| **关闭** | 服务不启动，不占端口。谁都连不上。 |
| **只读** | 开放 6 个查看功能。不会修改任何文件。 |
| **可写** | 本版**还做不到**写操作，实际行为等同只读。 |
| **每次审批** | 同上。每个操作都要你点确认。 |

**怎么算通过：**

- 「只读」和「可写」「每次审批」这三个在**本版行为上应该完全一样**（都是只读）。
- 如果你在「可写」档位下发现 AI 居然能删除或改名文件，**立刻停下告诉我** —— 这是绝对不能发生的。

**再验证「关闭」是真关：**

1. 记下刚才那个端口号（比如 55123）。
2. 把档位改回「关闭」。
3. 状态应该变回「未运行」，端口号消失。

---

## 六、验收第四步：让 AI 助手真的连上并干活

这是最核心的一步：**让一个真的 AI 助手连上来并读你的文件。**

### 你需要做的

1. 在「MCP 服务」页，点 **「复制配置片段」**（把配置复制到剪贴板）。
2. 打开剪贴板看一下（可以用记事本粘一下），里面应该是一段可以照抄的配置。

### 接 Minimax Code（本机已装，最方便）

把复制到的配置交给 Minimax Code，让它添加这个 MCP 服务。添加完成后：

3. 回到应用，看 **状态栏**（窗口底部那一条）。

**你应该看到：** 底部出现一个小徽标，写着 **「1 个 agent 已连接」**。

### 接 Claude Code

Claude Code 用一条命令添加（把 `<>` 里的内容换成你复制的配置）：

```
claude mcp add --transport http alpha-file http://127.0.0.1:55100/mcp --header "Authorization: Bearer <你的token>"
```

> 注意：端口号和 token 要用**你现在页面上显示的那一套**。每次重新生成 token，命令里的 token 也要跟着换。

添加完成后，状态栏同样应该出现「1 个 agent 已连接」。

---

## 七、验收第五步：让 AI 干六件真事

连上之后，在 AI 助手里依次问这六句。**每一句都该答得出真实内容，不是报错、也不是空。**

| # | 你问 AI 的话 | 正确答案长什么样 |
|---|---|---|
| 1 | 「用 Alpha 文件管理器列一下我电脑有哪些盘」 | 列出 C 盘、D 盘……带容量和剩余空间 |
| 2 | 「用 Alpha 列出 D:\某个目录 里有什么」 | 列出那个目录的真实文件 |
| 3 | 「用 Alpha 帮我找一个叫『合同』的文件」 | 找到真实存在的文件 |
| 4 | 「用 Alpha 算一下 D:\某个目录 占多大」 | 给出字节数或 GB |
| 5 | 「用 Alpha 看看我收藏了哪些东西」 | 列出你在应用里加星的分类 |
| 6 | 「用 Alpha 列一下可移动设备」 | 列出 U 盘 / 移动硬盘（没有就给空列表，不是报错） |

**怎么算通过：**

- 六句都能返回**你这台电脑上的真实数据**。
- 答错内容 = 失败。
- 报「没有这个工具」= 失败（说明没连上）。

> **小提示：** 第 2 步请用一个**你确实知道里面有什么**的目录，比如桌面。这样你才能一眼看出它答得对不对。

---

## 八、验收第六步：翻牌，看它到底做了什么

回到应用「MCP 服务」页面的最下面 —— **「最近调用」**。

**你应该看到：** 刚才那几次操作，一条一条列出来，每条写明：调用了哪个工具、什么时候、是「已放行」还是「已拒绝」。

**再让 AI 干一件坏事试试：**

在 AI 里说「用 Alpha 帮我删掉 D:\某个目录 下的某个文件」。

**你应该看到：**

- AI 那边的答案：**明确拒绝**，说这是只读服务，不能删。
- 应用这边：「最近调用」里出现一条 **「已拒绝」**。

**这是最重要的一条验收。** 它必须被拒绝。

---

## 九、验收第七步：状态栏徽标

在前六步过程中，盯一眼窗口底部：

- **没有任何 AI 连着时**：底部**不应该**出现徽标。
- **有 AI 连着时**：出现「N 个 agent 已连接」。
- **把 AI 关掉、等一分钟**：徽标应该自己消失。

> 徽标只统计「最近几分钟内真的发过请求」的客户端。它不是在数「连着的线」，所以偶尔闪一下是正常的。

---

## 十、验收第八步：换 token 能不能锁死旧配置

这一条验证「门锁真的换了」：

1. 在「MCP 服务」页点 **「重新生成 token」**。
2. 页面上应该提示：**旧配置立即失效**。

**然后验证它真的失效了：**

- 让 AI 助手**用旧 token** 再试一次 → **应该失败**。
- 用**新 token** 再试 → **应该成功**。

**怎么算通过：** 旧 token 必须用不了。如果旧 token 还能用，**这是严重问题，立刻告诉我**。

1. **第几项**没过。
2. **你看到的实际现象**（照抄屏幕上的字）。
3. **「最近调用」里那几行**写了什么（这是最关键的线索）。
4. AI 助手**原话问了什么**、**它怎么回答的**。
